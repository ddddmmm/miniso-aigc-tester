# IP 角色海报模板

> 用途：以 IP 角色为主角的创意海报，用于社媒、活动、周边宣传。
> 关键：角色外形必须与官方设定一致（颜色、五官、体型、标志性特征）。

## 模板

**角色：** {IP 名称}，{角色外观描述：体型/颜色/五官/标志性特征}
**场景：** {主题场景，如春游野餐/海边度假/城市街头}
**动作表情：** {动作}，表情{开心/治愈/酷}
**构图：** 角色位于画面中心，{景别}，{横版/竖版}
**光影色彩：** {光线}，主色调 {颜色}
**风格：** 3D 卡通渲染（与官方画风一致），精致高清
**角色一致性：** 严格保持角色的体型比例、五官位置、配色和标志性特征不变
**负面要求：** 不要改变角色外观、多余肢体、五官错位、杂色、乱码文字、陌生角色

## 示例（可直接使用·DUNDUN 墩墩鸡）

DUNDUN 墩墩鸡，圆滚滚的黄色小鸡，橙色小嘴和小短腿，头顶有一小撮呆毛，黑豆眼；春天的公园野餐场景，墩墩鸡坐在格纹野餐垫上，手里举着一块三明治，旁边有花篮、果汁和马卡龙；表情开心满足，眼睛弯成月牙；角色位于画面中心，中景，竖版；午后温暖阳光，嫩绿和鹅黄主色调；3D 卡通渲染，与官方画风一致，精致高清；严格保持墩墩鸡圆胖体型、橙色小嘴、黑豆眼和头顶呆毛不变；不要改变角色外观、多余肢体、五官错位、杂色、乱码文字。
