# IP 节日主题模板

> 用途：节日期间 IP 形象的主题创意。
> 与“节日促销图”的区别：本模板以 IP 角色为绝对主角，商品不出现或仅作点缀。

## 模板

**角色：** {IP 名称}，保持官方外观
**节日：** {春节/万圣节/中秋/圣诞}
**节日装扮：** {唐装、帽子、道具}
**场景：** {节日场景}
**动作：** {角色的节日动作}
**光影色彩：** {节日配色}
**风格：** 3D 卡通渲染，精致高清
**角色一致性：** 换装不换“人”，五官、体型、配色不变
**负面要求：** 不要改变角色特征、多余肢体、乱码文字

## 示例（可直接使用·DUNDUN 春节）

DUNDUN 墩墩鸡，圆滚滚的黄色小鸡，橙色小嘴和黑豆眼，头顶呆毛；春节主题：墩墩鸡身穿红色小唐装，头戴瓜皮帽，双手捧着一个大红包，站在挂着红灯笼和春联的门前，脚下有金色祥云和鞭炮；表情喜气洋洋；红金配色，温暖明亮；3D 卡通渲染，精致高清；换装不换“人”，保持墩墩鸡圆胖体型、橙色小嘴、黑豆眼和呆毛不变；不要改变角色特征、多余肢体、乱码文字。

## 备选（万圣节）
