# IP 联名场景模板

> 用途：IP 与名创优品商品/门店的联名创意，或 IP 与商品同框。
> 关键：角色特征和商品外观都要准确，融合自然。

## 模板

**联名双方：** {IP 角色} × {名创优品商品/门店场景}
**画面描述：** {角色如何与商品互动，如抱着商品、在门店里、使用商品}
**场景：** {场景，如名创优品货架区/主题房间/户外}
**构图：** 角色与商品都是清晰主体，{景别}
**光影色彩：** {光线}，色调 {明快/梦幻}
**风格：** 3D 卡通渲染，精致高清
**角色一致性：** 保持角色官方外观不变；商品与参考图一致
**负面要求：** 不要让角色“走样”、商品变形、错误 logo、多余角色、乱码文字

## 示例（可直接使用·吉伊卡哇 × 保温杯）

吉伊（Chiikawa），白色圆滚滚的小仓鼠外形小可爱，粉色腮红，小耳朵；联名名创优品保温杯：吉伊双手抱着一个比它还高的奶白色保温杯，杯身印着吉伊的卡通图案；场景是温馨的名创优品主题货架，背景有模糊的联名周边和暖色灯带；角色与商品都是清晰主体，中景，竖版；明亮柔和的灯光，粉色与奶白主色调；3D 卡通渲染，精致高清；保持吉伊的圆胖体型、白色绒毛、粉色腮红和小耳朵不变，保温杯与参考图一致；不要让角色走样、商品变形、错误 logo、多余角色、乱码文字。
